# Materiais Mapeados - Ensino de Programação para PcDV

Este documento reúne todas as ferramentas, metodologias e artigos mapeados que foram incluídos no portal IncluiDev. 

## Ferramentas e Linguagens Acessíveis

### 1. Quorum Language
- **Link**: https://quorumlanguage.com/
- **Tipo**: Linguagem de Programação / Ferramenta
- **Nível**: Básico, Técnico, Superior
- **Público**: Professores, Alunos
- **Descrição**: Primeira linguagem de programação baseada em evidências ("Evidence-based programming language"). Ela foi desenhada do zero para ser acessível a leitores de tela e fácil de aprender.
- **Referência**: Stefik, A. et al. (UNLV)

### 2. Accessible Blockly
- **Link**: https://developers.google.com/blockly/guides/configure/web/keyboard-nav
- **Tipo**: Ferramenta / Framework
- **Nível**: Básico
- **Público**: Professores, Público Específico
- **Descrição**: Um esforço da Google para adicionar navegação por teclado e suporte a leitores de tela na sua biblioteca de programação em blocos visuais, tornando o conceito de blocos acessível a pessoas cegas.
- **Referência**: Google Developers

### 3. Code Jumper
- **Link**: https://codejumper.com/
- **Tipo**: Metodologia Física / Ferramenta
- **Nível**: Básico
- **Público**: Professores, Alunos
- **Descrição**: Originalmente "Project Torino" da Microsoft, o Code Jumper permite que os alunos escrevam código conectando módulos físicos grandes ("pods"), ensinando conceitos como sequências e loops de forma tátil e sonora.
- **Referência**: Microsoft / APH (American Printing House for the Blind)

### 4. Swift Playgrounds & VoiceOver
- **Link**: https://www.apple.com/swift/playgrounds/
- **Tipo**: Aplicativo / Ambiente de Ensino
- **Nível**: Básico, Técnico
- **Público**: Alunos, Público Geral
- **Descrição**: O aplicativo da Apple para ensinar Swift possui suporte nativo e aprimorado para o VoiceOver, permitindo que usuários com deficiência visual naveguem por quebra-cabeças e escrevam código usando áudio-descrições.
- **Referência**: Apple Accessibility

### 5. JBrick (LEGO Mindstorms)
- **Link**: https://sourceforge.net/projects/jbrick/
- **Tipo**: IDE / Ferramenta
- **Nível**: Técnico, Superior
- **Público**: Alunos, Público Específico
- **Descrição**: Um ambiente de desenvolvimento Java (IDE) totalmente acessível via leitores de tela, criado especificamente para permitir que estudantes cegos programem robôs LEGO Mindstorms.
- **Referência**: Ludi, S. et al.

## Artigos, Revisões e Guias Metodológicos

### 6. Configuração de IDEs para Leitores de Tela (VS Code)
- **Link**: https://code.visualstudio.com/docs/editor/accessibility
- **Tipo**: Guia
- **Nível**: Técnico, Superior
- **Público**: Alunos, Público Geral
- **Descrição**: Documentação oficial sobre as melhores práticas para utilizar o VS Code (Visual Studio Code) em conjunto com leitores de tela como NVDA ou JAWS.
- **Referência**: Documentação Oficial VS Code

### 7. Padrões de Acessibilidade Web (WCAG)
- **Link**: https://www.w3.org/WAI/standards-guidelines/wcag/
- **Tipo**: Guia / Norma Técnica
- **Nível**: Técnico, Superior
- **Público**: Professores, Público Geral
- **Descrição**: As diretrizes oficiais do W3C para garantir que aplicações web e ferramentas de programação online (como IDEs web) sejam acessíveis a pessoas com deficiência.
- **Referência**: W3C Web Accessibility Initiative (WAI)

### 8. Physical Programming for Blind and Low Vision Children at Scale
- **Link**: https://doi.org/10.1080/07370024.2019.1621175
- **Tipo**: Artigo Acadêmico / Estudo Empírico
- **Nível**: Básico, Superior
- **Público**: Professores, Público Específico
- **Descrição**: Estudo empírico focado diretamente no ensino de programação para *crianças* com deficiência visual usando interfaces físicas e tangíveis. Aborda o uso prático de metodologias inclusivas em larga escala.
- **Referência**: Morrison, C., et al. (Taylor & Francis - HC-I)

### 9. Making Programming Accessible to Learners with Visual Impairments: A Literature Review
- **Link**: https://doi.org/10.21585/ijcses.v2i2.25
- **Tipo**: Revisão de Literatura
- **Nível**: Superior
- **Público**: Professores, Público Específico
- **Descrição**: Uma revisão de literatura (Review) que mapeia estratégias (como feedback háptico e de áudio) para tornar a programação acessível. O artigo destaca especialmente as lacunas no ensino focado em crianças (primary-aged).
- **Referência**: Hadwen-Bennett, A., Sentance, S., & Morrison, C. (IJCSES, 2018)

### 10. A Systematic Review on Developing Computer Programming Skills for Visually Impaired Students
- **Link**: https://scholar.google.com/scholar?q=A+Systematic+Review+on+Developing+Computer+Programming+Skills+for+Visually+Impaired+Students+2024
- **Tipo**: Revisão Sistemática
- **Nível**: Superior
- **Público**: Professores, Público Geral
- **Descrição**: Uma revisão sistemática recente (2024) cobrindo pesquisas entre 2000-2023. Foca em como tecnologias assistivas evoluíram e mapeia os desafios contínuos tanto para linguagens baseadas em texto quanto visuais.
- **Referência**: Journal of Disability Research (2024)
