# Personas e Jornadas de Usuário - IncluiDev

## Visão Geral

Este documento apresenta as personas e jornadas de usuário utilizadas como base para o desenvolvimento do IncluiDev.

As personas representam os principais públicos atendidos pelo portal e foram construídas a partir dos objetivos do projeto, da literatura analisada e das discussões realizadas durante a orientação do Trabalho de Conclusão de Curso.

O objetivo é garantir que a estrutura do repositório, os fluxos de navegação e o Assistente Guiado atendam necessidades reais dos usuários envolvidos no ensino de programação para Pessoas com Deficiência Visual (PcDV).

---

# Persona 1 — Estudante

## Perfil

**Nome:** Ana Clara

**Idade:** 17 anos

**Nível de Ensino:** Ensino Médio

**Características:**

* Possui deficiência visual total.
* Utiliza NVDA diariamente.
* Tem interesse em programação e tecnologia.
* Está iniciando seus estudos em computação.

---

## Objetivos

* Aprender programação.
* Encontrar ferramentas acessíveis.
* Descobrir metodologias adequadas para PcDV.
* Desenvolver habilidades para ingresso em cursos técnicos ou superiores.

---

## Dificuldades

* Conteúdos frequentemente dependem de recursos visuais.
* Falta de conhecimento sobre ferramentas acessíveis.
* Dificuldade para localizar materiais organizados em um único local.
* Pouca oferta de exemplos voltados para PcDV.

---

## Necessidades

* Ferramentas compatíveis com leitores de tela.
* Linguagens acessíveis para iniciantes.
* Tutoriais práticos.
* Recursos organizados por nível de ensino.

---

## Cenário de Uso

Ana deseja iniciar seus estudos em programação, mas não sabe quais ferramentas são acessíveis para usuários cegos.

Ela acessa o IncluiDev e utiliza a Busca Guiada para encontrar recursos adequados ao seu perfil.

# Contribuição para o Projeto

As personas e jornadas apresentadas servem como base para:

* Estruturação da navegação do portal.
* Desenvolvimento do Assistente Guiado.
* Organização da taxonomia dos conteúdos.
* Planejamento de testes de usabilidade.
* Avaliação da experiência do usuário.
* Validação do sistema junto aos diferentes públicos-alvo.

A utilização dessas personas contribui para que o IncluiDev mantenha foco nas necessidades reais dos usuários e fortalece a fundamentação metodológica do projeto de TCC.
